# Chapter one source contract

A new native character is unawakened. The avatar menu supports male/female identity selection, then the player starts at the hospital and meets Doctor Mira. The player walks to the Awakening Hall and meets Elder Seraphine before touching the crystal. The server draws one of eleven elements and records it at Basic mastery; reload and repeated interaction cannot reroll it.

Elements: Fire, Water, Air, Earth, Space, Shadow, Dark, Light, Electric, Summon, Healing. Stages: Basic, Real, High, Advanced, Super, Perfect. Fusion requires both parents at Advanced and creates Basic fusion mastery.

The magic trial requires actual target hits, a dodge and an element interaction. Server-approved cast proofs gate hits. A Guardian encounter has two phases and confirmed defeat; merely sending a story event cannot complete it. The city visit chapter tracks hospital, academy, guild hall, houses, market, bank and inn separately. Returning to Seraphine unlocks the final Seal/Study choice. The rules save stores the choice and progression.

The runtime district contains engineering geometry and native interactions. It has not been played in Unreal here. Avatar identity is implemented; realistic rigged character assets, animation graphs, final interiors, authored map art and final cinematics remain outstanding.

Spell development is represented by parameter validation, experimentation, stabilization, two successful reproductions and registration. A complete in-game spell editing UI is not yet delivered. The browser spell designer is a design reference and does not prove native UI functionality.

Additional elements are represented in mastery/save validation and fusion rules, but this chapter exposes only the initial awakening crystal. A later-element awakening flow and native fusion UI are unfinished. Fusion tests use validated second-affinity fixtures; they do not prove a player can unlock a second element in the native chapter.
